# Contributing to Project Good Boy

Thanks for your interest in contributing!

## How to Contribute

1. **Open an issue first** — Before making changes, please open an issue to discuss what you'd like to do
2. **Fork the repo** — Create your own fork to work on
3. **Make your changes** — Keep commits focused and descriptive
4. **Submit a PR** — Reference the issue in your pull request

## Guidelines

- **Code style** — Follow the existing code style in the project
- **Test your changes** — Make sure the firmware compiles and the web UI works
- **Document changes** — Update the README if you add new features

## Hardware Changes

If you're proposing electrical or mechanical changes:
- Include a schematic or diagram
- Document any safety considerations
- Note any changes to the BOM

## Questions?

Open an issue and we'll be happy to help!
